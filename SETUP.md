# Установка по шагам

Онлайн-версия с прогрессом и скриншотами: **https://factorychecklist.ikigaipromotion.kz** — здесь то же самое текстом, на случай если удобнее читать в редакторе.

## Шаг 1. Приложение Claude

Скачайте и установите:

- [Windows (x64)](https://claude.ai/api/desktop/win32/x64/setup/latest/redirect) · [Windows (ARM64)](https://claude.ai/api/desktop/win32/arm64/setup/latest/redirect)
- [macOS](https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect)

Войдите в аккаунт. Нужен тариф **Pro ($20/мес)** — на бесплатном плане вкладка Code не откроется.

Claude Code уже встроен в приложение: **отдельно ставить Node.js и CLI не нужно**.

## Шаг 2. Подготовка системы

**Windows:** поставьте [Git for Windows](https://git-scm.com/downloads/win) и **перезапустите приложение Claude**. Без git локальные сессии в Code не работают.

**macOS:** в Терминале
```bash
xcode-select --install
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

## Шаг 3. Папка проекта

Создайте папку: `C:\Claude\content-factory` (Windows) или `~/Claude/content-factory` (macOS).

В приложении: вкладка **Code** → окружение **Local** → **Select folder** → выберите её.

Работайте только во вкладке Code. Home/Chat не видит файлы, а Cowork берёт настройки из claude.ai — комплект там не подхватится.

## Шаг 4. Окружение

Вставьте в чат промпт для своей системы.

**Windows:**
```

Сначала покажи, что уже стоит: node --version, git --version, ffmpeg -version, winget --version.
Ничего не переустанавливай, если версия подходит (Node нужен 20 или новее).
Чего нет — поставь через winget: OpenJS.NodeJS.LTS, Gyan.FFmpeg, yt-dlp.yt-dlp.
Спрашивай разрешение перед каждой установкой и объясняй простыми словами, что делаешь.
В конце покажи итог: что было, что поставили, что осталось сделать вручную.
```

**macOS:**

## Шаг 6. Higgsfield (картинки и видео)

1. Регистрация на [higgsfield.ai](https://higgsfield.ai), выберите тариф (от $15/мес).
2. В приложении Claude: **Customize → Connectors** → добавьте адрес `https://mcp.higgsfield.ai/mcp` с именем `Higgsfield`.
3. Войдите в свой аккаунт Higgsfield в открывшемся браузере.

Ключ API не нужен. Генерация тратит кредиты вашего тарифа.

## Шаг 7. fal.ai (картинки топ-моделями)

1. Регистрация на [fal.ai](https://fal.ai), создайте ключ в разделе Keys, пополните баланс на $5–10.
2. Вставьте в чат:

```
Подключи fal.ai. Создай в корне рабочей папки файл .mcp.json с сервером fal:
type http, url https://mcp.fal.ai/mcp, заголовок Authorization: Bearer <мой ключ>.
Ключ я вставлю сам — оставь на его месте заглушку и покажи, какую строку заменить.
Тот же ключ добавь в engine/.env как FAL_KEY.
```

Ключ никому не показывайте и замазывайте на скриншотах.

## Шаг 8. Ключ OpenAI (расшифровка речи)

`platform.openai.com` → API keys → создать ключ `sk-...` → пополнить баланс на $5 → вписать в `engine/.env` как `OPENAI_API_KEY`.

## Шаг 9. Финальная проверка

```
Прогони финальную проверку контент-фабрики:
1. node reels/check-deps.mjs в папке engine
2. смонтируй демо-ролик: node reels/montage/run.mjs demo/demo.config.mjs
3. открой готовый файл и скажи, сколько секунд получилось и сколько склеек
4. проверь, что Higgsfield подключён — сгенерируй одну тестовую картинку
Выведи итог списком: что зелёное, что красное.
```
