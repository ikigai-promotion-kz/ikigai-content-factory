# Установка контент-фабрики

Ты ставишь контент-фабрику человеку, который **не программист**. Он пришёл на интенсив, чтобы делать контент, а не разбираться в терминале.

## Как себя вести

- Объясняй каждый шаг **одной строкой человеческим языком**: что сейчас делаешь и зачем. Без слов «зависимости», «бинарник», «пайплайн».
- **Спрашивай разрешение перед установкой любой программы.** Скажи, что ставишь и сколько это займёт.
- Дошёл до ошибки — не молчи и не выдумывай. Покажи, что именно не вышло, и предложи следующий шаг.
- В конце **обязательно** покажи готовый смонтированный ролик. Установка засчитана только так.
- Никогда не проси прислать ключи в чат. Ключи человек вписывает сам в файл `.env`.

## Шаг 1. Что уже есть

Проверь и скажи человеку результат простым списком «есть / нет»:

- `node --version` — нужна 20 или новее
- `git --version`
- `ffmpeg -version` и `ffprobe -version`
- на Windows: `winget --version` · на macOS: `brew --version`

Ничего пока не ставь. Сначала покажи картину целиком.

## Шаг 2. Доставить, чего не хватает

Windows (PowerShell):

```powershell
winget install --id OpenJS.NodeJS.LTS --accept-source-agreements --accept-package-agreements
winget install --id Gyan.FFmpeg --accept-source-agreements --accept-package-agreements
winget install --id yt-dlp.yt-dlp --accept-source-agreements --accept-package-agreements
```

macOS:

```bash
brew install node ffmpeg yt-dlp
```

Важное про Windows: после установки `ffmpeg` текущее окно приложения может его не увидеть — это нормально, PATH обновляется при перезапуске. Скажи об этом человеку заранее, чтобы он не пугался. Фабрика умеет находить ffmpeg и мимо PATH, так что чаще всего перезапуск не понадобится.

Если на macOS Claude просит разрешение на сетевые домены — так и должно быть, это песочница. Пусть разрешает.

## Шаг 3. Забрать движок

Если комплект уже склонирован (ты читаешь этот файл из папки `factory`) — шаг клонирования пропусти и переходи к установке зависимостей.

```bash
git clone https://github.com/ikigai-promotion-kz/ikigai-content-factory.git factory
cd factory/engine
npm install
npx playwright install chromium
```

**Все дальнейшие команды выполняются из папки `factory/engine`.** Если сессия перезапустилась и текущая папка сбилась — сначала вернись в `factory/engine`, потом запускай.

Скажи, что `playwright` — это браузер, которым фабрика рисует титры и субтитры. Он весит около 150 МБ, качается один раз.

## Шаг 4. Ключи

Скопируй `factory/engine/.env.example` в `factory/engine/.env` (Windows: `copy`, macOS: `cp`) и объясни человеку, что вписать. **Сам ключи не запрашивай и не вставляй** — покажи строку и путь к файлу, человек вписывает сам:

- `OPENAI_API_KEY` — расшифровка речи для субтитров. Без него монтаж работает, но текст субтитров придётся давать вручную.
- `FAL_KEY` — генерация картинок. Нужен со второго дня.

Higgsfield ключом **не подключается**: в приложении Claude это `Customize → Connectors → https://mcp.higgsfield.ai/mcp`, вход через браузер. Если человек этого ещё не сделал — подскажи, но не блокируй установку.

Для fal есть готовый образец: скопируй `factory/.mcp.json.example` в `.mcp.json` **корня рабочей папки** (не внутрь `factory`) и покажи человеку строку с ключом. Заново такой файл не сочиняй.

## Шаг 4а. Правила проекта

Скопируй `factory/CLAUDE.md.template` в `CLAUDE.md` в корне рабочей папки. Это файл, который Claude читает автоматически в каждой сессии: бренд, голос, стоп-слова, правила работы с видео и деньгами.

Пройдись по нему вместе с человеком и заполни угловые скобки его словами — спрашивай по одному пункту, не вываливай всю анкету сразу. Не знает ответа — оставь плейсхолдер и скажи, что вернётесь к этому после домашнего задания.

## Шаг 5. Проверка

```bash
node reels/check-deps.mjs
```

Разбери вывод вместе с человеком: что зелёное, что нет. `СТОП` — возвращайся к шагу 2.

## Шаг 6. Первый ролик — это и есть приёмка

```bash
node reels/montage/run.mjs demo/demo.config.mjs
```

Прогон занимает 1–2 минуты: фабрика вырезает паузы, режет видео на планы, накладывает субтитры и титры. Кредиты не тратятся — всё считается на машине человека.

Когда файл готов — **открой его** (Windows: `start`, macOS: `open`) и скажи, что именно он видит: сколько было секунд, сколько стало, сколько получилось склеек. Затем предложи следующий шаг: смонтировать его собственное видео.

## Своё видео

Нужны два файла: видео и расшифровка речи с таймкодами слов. Дальше конфиг по образцу `reels/montage/example.config.mjs` — там описано каждое поле: свой заголовок-хук, свои титры на нужных фразах, свой финальный кадр.

Если расшифровки нет, а ключ OpenAI есть — сними её:

```bash
node reels/transcribe.mjs ./его-видео.mp4
```

Рядом появится `его-видео.words.json` — этот путь идёт в поле `wordsPath`. Расход ~$0.006 за минуту, назови сумму до запуска. Если ключа нет, скажи прямо: без расшифровки субтитры и нарезка по фразам не поедут.
