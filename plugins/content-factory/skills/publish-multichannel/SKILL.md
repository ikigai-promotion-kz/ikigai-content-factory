# Публикация в несколько каналов

Готовый пакет к выпуску (папка от `reels/release.mjs`) уходит в выбранные каналы
одной командой. Между «собрано» и «опубликовано» стоит человек — и это единственная
часть, которую нельзя выкинуть.

## Главное правило

**Приёмка глазами до публикации, а не после.**

Скрипт умеет отправить всё разом, и именно поэтому он по умолчанию ничего не
отправляет: без флага `--yes` он показывает план и выходит. Не подсовывай `--yes`
сам, «чтобы человеку было меньше действий». Мы уже выключали свою первую ферму
за то, что она публиковала быстрее, чем кто-либо успевал посмотреть результат.

Что человек должен увидеть до отправки:
- ролик — **на телефоне**, а не на мониторе: мелкий титр на экране читается, на
  телефоне превращается в шум;
- первый кадр — он же превью в ленте;
- подпись целиком, особенно первые 125 знаков: остальное площадка спрячет.

## Что нужно завести один раз

**Аккаунт Upload-Post** — посредник с одним API на два десятка площадок.
Прямые интеграции мы не делаем осознанно: каждая площадка — это своё
приложение-разработчика, своё ревью и свой протухающий токен. На LinkedIn и Meta
на этом теряют недели.

1. Регистрация на upload-post.com.
2. Создать **профиль** и подключить к нему свои соцсети. Профиль — это связка
   аккаунтов; в `.env` идёт именно его имя, не почта.
3. `Settings → API Keys` → ключ.
4. В `engine/.env`:
   ```
   UPLOAD_POST_API_KEY=...
   UPLOAD_POST_USER=имя-профиля
   ```

**Тарифы, о которых надо сказать вслух:** Free — 10 публикаций в месяц, 2 профиля,
карту не спрашивают, **но без TikTok**. Basic $24/мес — без лимита публикаций,
5 профилей, TikTok есть. Начинать с Free правильно: он даёт проверить всю цепочку
до того, как человек за что-то заплатит.

## Как публиковать

Пакет собран `reels/release.mjs` — в нём лежит `manifest.json`, и публикатор
читает именно его, а не угадывает по именам папок. Пакеты, собранные старой
версией движка, надо пересобрать.

```bash
# 1. Посмотреть план. Ничего не отправляется.
node publish/publish.mjs tmp/release-моя-тема

# 2. Отправить: каждая папка уходит в свою родную площадку
node publish/publish.mjs tmp/release-моя-тема --yes

# 3. Только выбранные каналы из пакета
node publish/publish.mjs tmp/release-моя-тема --to=instagram,youtube --yes

# 4. Одна папка — в несколько каналов сразу
node publish/publish.mjs tmp/release-моя-тема/03-telegram --to=telegram,linkedin --yes
```

Всегда сначала показывай человеку вывод без `--yes` и жди подтверждения.

## Что какой канал принимает

| Канал | Видео | Фото-карусель | Только текст |
|---|---|---|---|
| Instagram | Reels | да, до 10 слайдов | нет |
| TikTok | да | да (фото-пост) | нет |
| YouTube | Shorts и обычные | нет | нет |
| LinkedIn | да | да | да |
| Facebook | да | да | да |
| X | да | да | да |
| Threads | да | да | да |
| Telegram | да | да | да |
| Pinterest | да | да | нет |

Заголовок и текст — разные поля только у YouTube: `title` там имя ролика на
100 знаков, а весь текст живёт в описании. У остальных площадок подпись одна.
Движок это уже учитывает, но если человек шлёт папку YouTube ещё куда-то —
предупреди, что туда уедет короткий заголовок, а не подпись.

## Грабли, о которых надо сказать заранее

- **Один канал дважды за прогон.** Reels и карусель обе идут в Instagram. Два
  поста в один час делят охват между собой. Скрипт предупредит, но решает человек:
  разнести по времени через `--to=` по одному.
- **Тексты писались под свою площадку.** Отправляя папку Telegram ещё и в LinkedIn,
  человек берёт текст с телеграмными лимитами и тоном. Скрипт скажет об этом;
  не проглатывай предупреждение молча.
- **Предохранитель на 6 публикаций в сутки** (`MAX_POSTS_PER_DAY`). Он не про
  лимит площадки, а про сорвавшееся расписание: цикл способен за ночь выложить
  полсотни постов и угробить аккаунт.
- **Фото тяжелее 8 МБ Instagram не примет.** Скрипт проверит до отправки.
- **Успех загрузки ≠ хороший пост.** API рапортует, что файл принят. Как пост
  выглядит в ленте — видно только глазами в приложении. Проси человека проверить.

## Когда что-то не прошло

Смотри `publish/log/<дата>.jsonl` — там сырой ответ площадки. Разбор по частоте:

1. **Аккаунт не подключён к профилю** — самое частое. Проверяется в интерфейсе
   Upload-Post, там же видно, какие соцсети привязаны.
2. **Токен площадки требует переподключения** — соцсети отзывают доступ сами
   по себе, раз в несколько месяцев это нормально.
3. **Формат не подходит каналу** — например, карусель в YouTube.
4. **Кончился лимит тарифа** — на Free это 10 публикаций в месяц.
5. **Файл не там** — пакет перемещали или пересобирали.

Не чини это выдумыванием обходных путей и не предлагай публиковать через
браузерную автоматизацию: площадки её ловят и банят аккаунты.

## Чего этот скилл не делает

- **Не решает, готов ли выпуск.** Это работа человека и скиллов `content-set`,
  `carousel-factory`, `reels-montage`.
- **Не ставит расписание.** Публикация по таймеру — это отдельная тема, у неё
  свои требования (сервер и отдельный ключ Claude API): `avtopilot.ikigaipromotion.kz`.
- **Не пишет тексты.** Они уже лежат в пакете, принятые человеком.
- **Не собирает метрики.** Сбор охватов — задача Apify, а не публикатора.
