# Установка

Комплект ставится одной командой. Ниже — что она делает и что делать, если что-то пошло не так.

Полный ручной путь с картинками, регистрациями и ключами — в [SETUP.md](SETUP.md).
Эта страница — короткая версия для тех, у кого папка уже скачана.

---

## Одна команда

Откройте терминал **в папке комплекта** — там, где лежат `engine/` и `plugins/`.

**Windows**

```
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

**macOS и Linux**

```
bash install.sh
```

Всё. Дальше — впишите ключи и откройте [ПЕРВЫЙ-ЗАПУСК.md](ПЕРВЫЙ-ЗАПУСК.md).

## Что она делает

| Что | Куда кладёт |
|---|---|
| Семь навыков фабрики | `<проект>/.claude/skills/` |
| `CLAUDE.md` — правила вашего бренда | корень проекта |
| `.mcp.json` — подключение fal | корень проекта |
| `.env` — ключи | рядом с движком, `engine/.env` |

Плюс печатает таблицу «что стоит на машине»: node, npm, git, ffmpeg, yt-dlp.
Ничего не устанавливает сама — только показывает, чего не хватает.

**Куда именно.** По умолчанию проект — это папка **над** комплектом. После клонирования
движок лежит в `<проект>/factory`, значит настройки лягут в `<проект>`, рядом с ним.
Так обновление движка не затирает то, что вы настроили под себя.

Другая папка — укажите её явно:

```
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Project C:\Claude\content-factory
bash install.sh --project ~/Claude/content-factory
```

Первая строка вывода всегда показывает, куда именно всё поедет. Если путь не тот — нажмите
`Ctrl + C` и запустите с ключом `-Project` / `--project`.

## Что она НЕ делает

**Не перезаписывает молча.** Навык, который уже стоит, пропускается — список пропущенного
печатается в конце. Это значит, что установщик можно запускать сколько угодно раз:
второй запуск ничего не сломает.

**Не трогает ваши файлы никогда.** `CLAUDE.md`, `.env` и `.mcp.json` создаются, только если
их ещё нет. Даже с ключом `-Force` они остаются вашими — там ваш бренд и ваши ключи.

**Не ставит программы.** Node, ffmpeg и остальное — отдельный шаг: откройте проект во вкладке
**Code** и попросите Claude «доустанови то, чего не хватает». Готовый промпт — в
[SETUP.md](SETUP.md), шаг 2.

**Не качает зависимости движка**, если не попросить. Нужно — добавьте ключ:

```
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Deps
bash install.sh --deps
```

## Ключи

| Ключ | Обязателен | Зачем |
|---|---|---|
| `FAL_KEY` | **да** | генерация картинок и музыки. Единственная обязательная платная операция |
| `OPENAI_API_KEY` | нет | точная расшифровка речи. Бесплатный способ уже встроен: `node reels/transcribe-local.mjs` |
| `APIFY_TOKEN` | нет | поиск доноров в Instagram. YouTube и Shorts фабрика ищет бесплатно |
| `UPLOAD_POST_API_KEY` | нет | публикация в несколько каналов одной командой |

Ключа Anthropic здесь нет намеренно: думает за фабрику сам Claude Code, в котором вы работаете.
Второй раз за ту же модель платить не нужно. Подробности — внутри `engine/.env`, там у каждого
ключа написано, где его взять и сколько это стоит.

Higgsfield подключается **без ключа**: в приложении Claude → **Customize → Connectors** →
`https://mcp.higgsfield.ai/mcp`.

## Если не сработало

**«Выполнение сценариев отключено в этой системе»** — вы запустили `install.ps1` без ключа
`-ExecutionPolicy Bypass`. Скопируйте команду целиком, вместе с этим ключом.

**«это не папка комплекта»** — терминал открыт не там. Перейдите в папку, где лежат `engine/`
и `plugins/`, и запустите ещё раз.

**Навыки не появились в списке `/`** — Claude Code читает список навыков один раз при старте
сессии. Перезапустите приложение и наберите `/`.

**ffmpeg «не найден» сразу после установки** — это нормально: в уже открытом окне PATH не
обновился. После перезапуска приложения всё будет видно. Сам PATH не правьте.

**Хочу поставить фабрику во все проекты, а не только в эту папку** — поставьте её плагином:
в приложении **+ → Plugins → Add plugin**, маркетплейс `ikigai-promotion-kz/ikigai-content-factory`.
В терминальной версии: `/plugin marketplace add ikigai-promotion-kz/ikigai-content-factory`.
