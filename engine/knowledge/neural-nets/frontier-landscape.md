# Frontier / вне Higgsfield — карта рынка и пробелов

> **Назначение:** карта передовых генеративных инструментов ВНЕ Higgsfield (Midjourney, Ideogram, Adobe Firefly, Runway, Luma, Pika, ElevenLabs, Suno/Udio, HeyGen/Synthesia, Genie 3). Отвечает на два вопроса движка: (1) где наш Higgsfield-стек уже держит паритет/сильнее и добавлять внешнее НЕ надо; (2) где реальный функциональный пробел, который стоит закрывать или хотя бы держать в поле зрения при клиентском брифинге.
> **Как использует движок:** reference-слой для `art-director.md` (брифинг клиентов «что умеет лучший инструмент на рынке») и будущего `model-router` (эталоны качества при оценке своих результатов). Питает апдейт `video-craft.md` §M10 свежими версиями (Gen-4.5 / Ray3.14 новее описанного там). Сейчас reference-слой, не runtime — пока не подключён в `lib/corpus.js`.
> **Дата:** 2026-07-11 · **Источник:** higgsfield.ai + офиц. доки + _SEED-mcp-catalog.md

> Не дублирует `knowledge/video-craft.md` §M10 (мультимодельный роутинг Higgsfield) / §M11 (post-edit). Здесь — только то, что НОВЕЕ или ОТСУТСТВУЕТ в нашем стеке. Кросс-ссылки в тексте.

Это тот же принцип, что уже зафиксирован для наших Soul ID / Element Consistency (N01/N02) — индустриальный консенсус, не совпадение.

## Video — вне Higgsfield

> Не дублирую `video-craft.md` §M10 (Motion Brush Pro/Act-One, Scene Ingredients/Pikaffects, Ray3 HDR/EXR/Multi-Keyframe, Hailuo). Ниже — **только новее или отсутствующее**.

### Runway Gen-4.5 (апдейт к M10)
Релиз 01.12.2025. **#1 в Artificial Analysis Text-to-Video Arena (1247 Elo)** — обошёл Google/OpenAI (CNBC). Построен на NVIDIA Hopper/Blackwell. Скорость Gen-4 при выше качестве, те же цены; все контрол-режимы (I2V, Keyframes, V2V) перенесены.
**Официальные ограничения (важны для брифинга о лимитах AI-видео ВООБЩЕ):** causal reasoning (эффект прежде причины — дверь открывается до нажатия ручки), object permanence (объекты пропадают между кадрами), success bias (неудачное действие в промпте модель всё равно «завершает успехом»).
**When-to-use (не наш стек):** эталон «на что способна лучшая модель прямо сейчас» — если клиент показывает референс с Gen-4.5, физика и temporal consistency там выше, чем у большинства нашего video-роутера, кроме Seedance 2.0 / Cinema Studio 3.0.

### Luma Ray3.14 (апдейт к M10 — новее описанного там Ray3)
С марта 2026 **Ray3.14 — новый дефолт** (Ray3 остаётся ТОЛЬКО ради Character Reference). Нативный 1080p + **HDR** + **EXR-экспорт** для цветокоррекции (⚠ EXR только на 540p/720p — на 1080p недоступен). 6 AR (вкл. 21:9 ultrawide). Длительность: 5с/10с t2v, 5с i2v, Modify (V2V) до 18с, extensions до ~30с.
**Позитив-онли модель** — негативный промптинг контрпродуктивен. ⚠ Это специфика ИМЕННО Luma, НЕ универсальное правило: наш `video-craft.md` §M10 держит «negative 3–5 терминов» для Kling/Veo/Seedance — не переносить луми-специфику бездумно.
**Запрещённые слова у Luma** (снижают качество): «vibrant», «whimsical», «hyper-realistic», «beautiful», «amazing», «stunning» + любые temporal-фразы («begins to», «starts to»). Формула: `[SUBJECT] [MID-ACTION VERB] в [SETTING], [SECONDARY MOTION], [CAMERA], [LIGHTING]`, ~100 слов, present tense.
**When-to-use (не наш стек):** эталон HDR/EXR-пайплайна, если у клиента профессиональный color-grading workflow.

### Pika 2.5/3.0 (апдейт к M10)
Помимо Pikaffects/Scene Ingredients (уже в M10): **авто-SFX под действие в кадре** (машина врезалась → «хруст металла» без отдельного промпта) и улучшенный **Lipsync** («viable конкурент HeyGen для локализованного персонажного контента» — по обзору). Тарифы 2026: Free 80 кред/мес (480p, watermark, без коммерции), Standard $8/мес (700 кред, коммерция), Pro $28/мес, Fancy $76/мес.
**When-to-use (не наш стек):** Pika Standard $8/мес дешевле входа в Higgsfield-подписку, но без multi-model роутинга и MCP.
⚠ LOW-CONFIDENCE: обзор от 02.2026, могли выйти свежее тарифы/фичи Pika 3.0.

### Adobe Firefly Video — Quick Cut + Project Moonlight
**Quick Cut** — сырой отснятый материал → структурированный первый монтаж за минуты (авто-эдит, не генерация). **Project Moonlight** (приватная бета, март 2026) — агентный conversational-интерфейс поверх Photoshop/Express/Acrobat: описываешь цель → агент выполняет реальные действия инструментами Adobe. Концептуально это прямой аналог того, к чему движется наш `/carousel-day` (агент-оркестратор поверх генерации), но у Adobe — с профессиональной редактурой внутри.
**When-to-use (не наш стек):** держать Project Moonlight как ориентир «куда идёт агентный creative workflow» у крупного игрока.

### World models — новый класс (ПРОБЕЛ, вне видео-генерации)
**Google DeepMind Genie 3** (анонс авг. 2025) — general-purpose world model: по тексту генерирует **исследуемую в реальном времени** фотореалистичную среду (не готовый клип, а мир, рендерящийся по мере движения/взаимодействия). Принципиально другая категория, чем t2v/i2v.
**When-to-use:** сейчас неприменимо к карусель/баннер-движку (нет продукта-обёртки для контента), но маркер направления рынка на случай «explore-мою-рекламу-как-мир» форматов.
⚠ LOW-CONFIDENCE: коммерческий/API-доступ на 07.2026 не подтверждён — похоже на research preview, не production.

## Audio — вне Higgsfield

### ElevenLabs v3 (сверить с нашим `text2speech_v2`)
Флагманская TTS (публичный API). **Audio tags** — инлайн-теги эмоции/паузы прямо в тексте (`[whispers]`, `[laughs]`, `[sarcastically]`) без отдельных параметров. **Dialogue Mode** — многоголосые диалоги с общим контекстом просодии между репликами (не последовательные отдельные вызовы). **70+ языков** (v2 — 29), вкл. русский.
**Сверка с seed:** наш `text2speech_v2` имеет `variant=elevenlabs` — но ⚠ **проверить в MCP**, отдаёт ли этот variant именно v3 с audio tags/Dialogue Mode или более раннюю версию движка. Если только базовый TTS без тегов — прямой API ElevenLabs даёт больше контроля для сложных многоголосых сценариев (напр. рекламный диалог с эмоциональными пометками). См. `higgsfield-audio-stack.md` (N03).
**When-to-use (вне Higgsfield):** нужен построчный контроль эмоции (audio tags) или multi-speaker с общим контекстом, а `text2speech_v2` этого не даёт.

### Музыка: Suno v5 / Udio / ElevenLabs Music — лицензия как главный критерий
| | Suno | Udio | ElevenLabs Music |
|---|---|---|---|
| Обучающие данные | Копирайтные записи (иск RIAA 06.2024, урегулирован к концу 2025) | То же (иск RIAA, урегулирован) | Лицензированные/royalty-free с нуля (запуск 08.2025) |
| Content ID / YouTube-риск | Средний (снижен, не нулевой) | Средний | **Низкий** — материально ниже |
| Сила | Лучший вокал (9.5/10), поп/рок | Лучшая кинематографика/оркестр (9/10) | Чистая лицензия + интеграция с голосовым стеком ElevenLabs |
| Слабость | Оркестровка (7/10) | Вокал менее естественный (7/10) | Качество ниже пиков Suno/Udio; музыка делит квоту символов с голосом |
| Цена (вход/про) | $10 / $30 | $10 / $30 | $5 / $22 / $99 (единый тариф с голосом) |

**Вывод для брендового контента:** музыка в публикуемую рекламу/карусель-видео под **монетизируемый канал клиента** → **ElevenLabs Music безопаснее по копирайту**, несмотря на чуть скромнее звучание. Наш `sonilo_music` (FAL, N03) — ⚠ **проверить условия использования Sonilo/Mirelo на коммерческий output так же строго**, как здесь разобран Suno/Udio.
⚠ У Suno/Udio коммерческая лицензия имеет оговорки об **indemnification** даже после урегулирования исков — «можно коммерчески» ≠ «нулевой юридический риск», читать актуальные ToS.

Запрос клиента на живой интерактивный аватар (чат-бот с лицом на сайте/вебинаре) → HeyGen LiveAvatar напрямую или D-ID, не наш текущий стек.

## Тренды 2025–2026 (сводно)
- **Character-consistency — везде:** Omni Reference (MJ), Character (Ideogram), Custom Models (Firefly), Character Reference (Luma Ray3) — конвергентная эволюция с нашими Soul ID / Element Consistency (Kling 3.0, Seedance 2.0). Разница глубины: разовый референс vs переобучаемая модель у Firefly.
- **4K — уже ожидание, не premium:** Ray3.14, Veo 3.1 (4K с реконструкцией текстуры кожи/пор), Gen-4.5, Ideogram/Firefly. Наш seed покрывает 4K (`seedance_2_0`/`gpt_image_2`/`nano_banana_pro`) — **паритет есть**.
- **Native-audio — гигиенический минимум** у видео-моделей (см. N02); новое — сдвиг разговора с «есть ли аудио» на «безопасен ли аудио по копирайту».
- **Real-time — нишевый, но два направления:** интерактивные аватары (HeyGen LiveAvatar) и интерактивные миры (Genie 3). Ни то ни другое не в нашем стеке.
- **World-models — зарождающаяся, не production** для рекламы (Genie 3). Следить, не внедрять.

## Грабли и особенности
- **Midjourney V8.1 — ловушка для брифинга:** «последняя версия» ≠ «все фичи доступны» — Omni Reference/Character Weight только через фолбэк на V7. Не путать «быстрее» с «функциональнее».
- **Luma Ray — «позитив-онли» промптинг** — НЕ универсальное правило нашего M10. Не переносить на Kling/Veo/Seedance.
- **HDR/EXR у Ray3.14 только на 540p/720p, НЕ на 1080p** — если нужны и HDR-пайплайн, и макс. разрешение — выбирать.
- **Adobe Firefly — не единая модель, а маркетплейс** (включая наши же конкурентные Veo/Kling/Runway внутри UI) — «Firefly vs Higgsfield» = сравнение UI/workflow-слоя, а не базовых генеративных моделей.
- **Прямого пути «добавить через fal/API» почти нет:** у Midjourney нет офиц. API (Discord/web), Firefly закрыт (enterprise); Ideogram/Runway/Pika/ElevenLabs имеют собственные прямые API (не fal) — но под каждый инструмент отдельная интеграция и отдельный биллинг, а не единый MCP как у Higgsfield.
