# Higgsfield PRESETS — каталог `preset_id`

> **Назначение:** реальные идентификаторы i2v-пресетов Higgsfield для `higgsfield_preset` (обязательный `preset_id`) и `cinematic_studio_video_v2` (опциональный `preset_id`).
> **Как использует движок:** reference-слой, `lib/corpus.mjs` его пока не читает. Нужен, когда карусель/слайд оживляется в клип без брифинга.
> **Дата дампа:** 2026-07-29 · **Источник:** `mcp__higgsfield__presets_show`, тариф с полным доступом

## Зачем этот файл появился

Прогон Higgsfield Academy (34 урока, 6 видео, 2043 кадра) не дал **ни одного** `preset_id` — только человекочитаемые названия режимов на панелях. `INTEGRATION-MAP.md` базы академии сознательно отказалась заводить такой файл: «пустышка дороже отсутствия». Живой MCP отдал 62 пресета с UUID — файл наполнился данными и потому существует.

## Главное ограничение — это НЕ камерные пресеты

Открытые обзоры фиксировали «50+ / 64 именованных пресета движения камеры» (Dolly In, Crash Zoom, Whip Pan, Bullet Time, Dutch Angle, FPV Drone). **В `presets_show` их нет.** Приходят два других семейства:

| Семейство | Что это | Сколько |
|---|---|---|
| `job_set_chain_preset` | Готовые вирусные **сценарии** с человеком в кадре («твой двойник заходит и делает селфи», «Y2K-папарацци») | 48 |
| `superhero-gen-preset` | Короткие **эффекты-трансформации** над фото | 14 |

На движение камеры из всех 62 работают ровно четыре: `ORBIT 360`, `FLOAT SPIN`, `EARTH ZOOM`, `Earth zoom in/out`. Остальное — сюжет, а не оптика.

**Вывод:** каталог camera-пресетов не подтверждён ни академией, ни MCP. Если он существует, то живёт в web-UI `/camera-controls` и наружу через API не отдаётся. Не искать его больше ни в академии, ни в `presets_show`.

## Что из этого применимо нам

Пресеты рассчитаны на лицо человека в кадре и развлекательный контент. Для делового контента годится узкая группа — та, что работает с **объектом**, а не с личностью:

| Задача | Пресет | Почему |
|---|---|---|
| Показать слайд/макет как физический предмет | `STICKER PEEL`, `ACTION FIGURE`, `CLAY FIGURINE`, `CARDBOARD CUTOUT` | рука вынимает объект из кадра — работает как «наша работа в руках» |
| Показать продукт со всех сторон | `ORBIT 360`, `FLOAT SPIN` | чистое движение камеры без сюжета |
| «Как это собрано» / разбор системы | `CGI BREAKDOWN`, `ANDROID ASSEMBLE`, `3D RENDER` | послойный разбор — визуальная метафора нашей фабрики |
| Масштаб / контекст рынка | `EARTH ZOOM`, `Earth zoom in/out` | заход из орбиты в сцену |

Всё остальное — папарацци, спорт-броадкасты, зомби, K-pop, файтинги — под наш бренд не идёт. Держим в каталоге ради полноты, а не как рекомендацию.

**Кастинг:** пресеты сгенерированы на европейской/азиатской внешности по умолчанию. Наше правило ~80% казахской внешности (`memory/casting-central-asia-kazakhstan`) через `preset_id` **не управляется** — пресет игнорирует промпт. Значит для контента с людьми пресеты не наш инструмент, только для объектов.

## Как вызывать

```
generate_video(model='higgsfield_preset', preset_id='<uuid>', medias=[<одно изображение>])
```
`higgsfield_preset`: ровно **одно** входное изображение (обязательно), AR 16:9 / 9:16 / 1:1, промпт не участвует — сценарий целиком в пресете.

```
generate_video(model='cinematic_studio_video_v2', preset_id='<uuid>', ...)
```
Здесь `preset_id` необязателен и комбинируется с `genre`, `mode`, `speedramp`, `multi_shots`, `cfg_scale`.

## Честные ограничения этого дампа

- **Список привязан к аккаунту и дате.** Higgsfield добавляет вирусные пресеты пачками; 62 — снимок на 29.07.2026 с тарифа с полным доступом. Перед боевым прогоном перечитывать `presets_show`, а не доверять файлу.
- **Цены не отдаются.** Ни `presets_show`, ни `models_explore` не возвращают стоимость — сколько стоит прогон конкретного пресета, видно только на кнопке Generate в web-UI.
- **Ни один пресет не проверен нами боем.** Описания — из API, не из нашего опыта. Столбец «применимо нам» выше — гипотеза по описанию.
- **У пресета `SOUL FIGHTER` описание в API битое** — начинается с «Claude responded:» и обрывается. Дефект на стороне Higgsfield, к вызову отношения не имеет.
