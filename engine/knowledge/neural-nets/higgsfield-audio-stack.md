# Higgsfield AUDIO-стек

> **Назначение:** карта аудио-возможностей Higgsfield MCP (`generate_audio` + voice-тулзы) — TTS, клонирование, дубляж, звукодизайн — с фокусом на русскую озвучку и на то, какие движки безопасны для продакшна.
> **Как использует движок:** reference-слой, не runtime. Питает будущий шаг озвучки роликов/Reels на базе карусели (см. `knowledge/video-craft.md` §M10/M11) и `model-router`. Для статичной карусели аудио не нужно — актуально только при переходе карусель→видео. Пока не подключён в `lib/corpus.js`.
> **Дата:** 2026-07-11 · **Источник:** higgsfield.ai + офиц. доки + _SEED-mcp-catalog.md

---

## 0. Архитектура: как устроен звук в Higgsfield

- **Higgsfield Audio** — вкладка внутри Cinema Studio-окна (не отдельная страница UI), три режима: **Voiceover** (TTS из текста), **Change Voice** (замена голоса в готовом видео/аудио) и **Translate** (перевод + дубляж + пересинхронизация губ).
- **Модели** идут через `generate_audio` (`params.model`): `text2speech_v2`, `seed_audio`, `inworld_text_to_speech`, `sonilo_music`, `mirelo_text_to_audio`.
- **Voice-cloning / dubbing / voice-swap** — это **отдельные тулзы**, НЕ модели `generate_audio`: `create_voice`, `create_voice_from_confirmed_audio`, `dubbing`, `voice_change`, `list_voices`.
- **Три режима Audio** используют общий voice-picker и одни и те же 5 TTS-движков `text2speech_v2`.

## 1. `text2speech_v2` — роутер к 5 TTS-движкам

Параметры (seed): `variant` `elevenlabs`/`minimax`/`seed_speech`/`vibe_voice`/`cozy_voice`; `voice_type` preset/element; `voice_id`.

| variant (seed id) | назначение | RU-статус | сильные | слабые | when-to-use у нас |
|---|---|---|---|---|---|
| `elevenlabs` (Eleven v3) | TTS + Dialogue Mode (multi-speaker) | ✅ **70+ языков вкл. ru** | inline audio-tags `[whispers]`/`[laughs]`/`[sighs]`; лучшее качество и эмоции; Text-to-Dialogue для 2+ голосов | API v3 GA только с 14.03.2026 — часть тегов voice-dependent | **Дефолт** для любой RU/EN озвучки с эмоцией; диалоги → Dialogue Mode |
| `cozy_voice` (CosyVoice 3.0, Alibaba) | TTS + zero-shot клон | ✅ **русский в базовых 9 языках** | zero-shot клон без файнтюна; latency ~150мс; instruct-режим (эмоции/скорость/громкость текстом); Apache-2.0 | нет коммерческого polish Eleven; акцент на азиатские языки | **Единственный кроме Eleven с явно подтверждённым RU** — приоритет для чисто-русской озвучки, если Eleven не устроит по цене/лимитам |
| `minimax` (MiniMax Speech 2.8 HD) | TTS + клон | ⚠ проверить в MCP | Native Sound Tags (хезитации "um/uh", вдохи — «живее»); клон по 10-сек сэмплу; кросс-лингвал без акцент-сдвига | нет паблик-списка языков с явным ru | длинные нарации/подкасты, где нужна человеческая пауза-хезитация |
| `seed_speech` (ByteDance Seed-TTS) | TTS multilingual | ⚠ проверить в MCP | топ по content-consistency/similarity среди closed-моделей | закрытая, нет паблик-доков по языкам | EN/ZH — надёжно по бенчмаркам; RU — только после проверки в MCP |
| `vibe_voice` (Microsoft VibeVoice) | multi-speaker long-form | ⚠ проверить в MCP | **до 90 мин** одним проходом, до 4 голосов; open-source (MIT), self-host возможен | чекпоинты фокус на en/zh | подкаст/диалог 2-4 спикера большой длительности (не наш короткий формат) |

**Промпт-советы (Eleven v3 / Speak 2.0, применимо к большинству движков):**
1. Пиши как сценарий: CAPS = акцент, `...` = пауза, короткие строки = быстрый темп.
2. Эмоции инлайн-тегами: `[whispers]`, `[sighs]`, `[laughs softly]` — модель играет текст, а не читает буквально.
3. Диалог — подписывай спикеров (`Sam: ... Alex: [French accent] ...`), модель разносит по голосам сама.
4. Длиннее промпт = естественнее звучание.

## 2. `inworld_text_to_speech` — Inworld TTS-1.5 Max (FAL)

- **RU-голоса подтверждены в API-схеме дословно (совпадают с seed):** `Svetlana`, `Elena`, `Dmitry`, `Nikolai`.
- Параметры: `voice` (enum, 100+ голосов), `text` до 2000 симв, `sample_rate_hertz` 8000–48000.
- Latency sub-200ms → годен для realtime/интерактива, не только batch. Входит в топ-3 TTS API 2026 по версии fal.
- **When-to-use:** быстрый RU TTS без клонирования, игровые/интерактивные пайплайны, когда не нужен эмоциональный range Eleven v3.

## 3. `seed_audio` — Seed Audio 1.0 (ByteDance): кино-звукодизайн

Не просто TTS: **T2A/TA2A/TTS в одной модели** — генерит кино-сцену одним промптом (речь + SFX + музыка + атмосфера) ИЛИ редактирует готовое аудио.

- Параметры (seed): `format` wav/mp3/pcm/ogg; `sample_rate`; `speech_rate`; `loudness`; `pitch`; `voice_type`+`voice_id`; image/audio refs (до 3 клипов ×30с, обращение `@Audio1..3`). Промпт ≤2048 симв, генерация ≤2 мин/проход (план июль 2026 — до 10 мин).
- **Режимы:** T2A (text-only → полная сцена), TA2A (text + `@Audio#` референс голоса), TTS (голос описан словами в промпте).
- **Редактирование:** extend (продолжить тем же голосом), inpaint (переозвучить конец, сохранив room tone), stitch (сшить 2 клипа), edit (заменить реплику, сохранив голос/тон).

**6-частная структура промпта для sound-design сцены:**
```
1. [Жанр + среда + настроение]
2. [Continuous sound bed — фон на всю сцену]
3. Speaker (голос-атрибуты + эмоция + темп) delivery verb: "Реплика."
4. [Конкретный SFX / переход]
5. Speaker (...) delivery verb: "Реплика, эскалирующая ситуацию."
6. [Тишина / финальный звук / муз. каденция]
```
Один сильный sound bed + пара точных cues > десять случайных SFX (модель «перегружается»).

⚠ **Языки: только English и Chinese** (июль 2026 обещает расширение). **Для RU-контента НЕ использовать** — брать Eleven v3 / CosyVoice. `⚠ проверить в MCP` — вышло ли языковое расширение.

## 4. Музыка и SFX (FAL, только для видео — не для карусели)

| модель (seed id) | тип | параметры | when-to-use |
|---|---|---|---|
| `sonilo_music` | text-to-music, **лицензированный контент** | `duration` (скорит видео до 600с) | фоновая музыка для роликов/Reels, где важна юридическая чистота лицензии |
| `mirelo_text_to_audio` | text-to-SFX | `duration` | SFX под видео (щелчки, шаги, амбиенс) без паразитной музыки |

⚠ **`mirelo` — несостыковка с seed.** Публично на fal найдена `mirelo-ai/sfx-v1` как **video-to-video** («видео = промпт», сама генерит синхронные SFX; заточена под AI-видео; blind-тесты 70-80% в пользу Mirelo). Seed же описывает `mirelo_text_to_audio` с `duration` (текстовый вход) — вероятно отдельный text-to-SFX эндпоинт. `⚠ проверить в MCP` — уточнить режим входа (text vs video).

## 5. Voice-тулзы: клон / дубляж / замена голоса

| тул | что делает | ключевое | грабли |
|---|---|---|---|
| `create_voice` / `create_voice_from_confirmed_audio` | клон голоса | сэмпл до ~2 мин чистой речи, consent, клон «за секунды»; до **3 кастомных голосов** на аккаунт + 40+ пресетов (Voiceover), 21 пресет (Change Voice) | сэмпл без шума/музыки/второго голоса — иначе клон «плывёт»; лимит слотов проверять в MCP |
| `voice_change` | замена голоса в готовом видео/аудио | **сохраняет слова и тайминг** (переозвучка по таймлайну, не пересинтез) | — |
| `dubbing` (Translate / AI Video Translator) | транскрипт → перевод → дубляж → **пересинхр. губ** покадрово | RU подтверждён с запуска (был в первой десятке) | ⚠ языки: блог запуска — 10 (вкл. Russian), лендинги — «74+». `⚠ проверить в MCP` — «74+» скорее для чистого TTS/voice-swap, не для dubbing-с-lipsync |
| `list_voices` | листинг пресетов/кастомных голосов | — | структура ответа `⚠ проверить в MCP` |

⚠ **Consent обязателен:** Higgsfield прямо запрещает клонировать реальных людей без разрешения — юридический риск для клиентских КП (нельзя клонировать голос конкурента/публичной персоны).

## 6. Нативное аудио видео-моделей (кросс-ссылка, без дублирования video-craft.md §M10/M11)

Если видео-модель поддерживает `generate_audio: true` / `sound: on` — **не гоняй отдельный `text2speech_v2` + муляж синхронизации**; нативный аудио-флаг дешевле и синхроннее.

| модель (seed id) | нативное аудио | когда брать |
|---|---|---|
| `seedance_2_0` | audio+video в один pass, до 9-12 refs (incl. audio) | звук таймится к движению автоматически |
| `veo3_1` | native audio | широкие/атмосферные сцены |
| `wan2_7` | native audio + lip-sync («dialogue without dubbing») | **диалог сразу с губами** без отдельного dubbing-прохода |
| `kling3_0` | Omni Native Audio + **Voice Binding** (один голос на персонажа через 5 языков, до 6 кадров-каты) | **персонаж с одним голосом** через мульти-шот сториборд |
| `gemini_omni` | native audio + voice binding (5 языков) | reference-driven t2v/i2v/v2v с голосом |

## 7. Решение: Higgsfield Audio vs прямой fal/ElevenLabs

- **Higgsfield Audio плюс:** единый MCP-воркфлоу (тот же вызов, что для картинок/видео); 5 TTS-движков под одной подпиской (не платить ElevenLabs отдельно); lip-sync для дубляжа из коробки.
- **Прямой fal/ElevenLabs плюс:** точечный контроль параметров модели без прослойки роутера; может быть дешевле при одной модели; на fal есть то, чего нет в Higgsfield audio-роутере — **`seed_audio` sound-design, `sonilo_music`, `mirelo` SFX** (Higgsfield покрывает голос/дубляж, но НЕ кино-звукодизайн/музыку/SFX как отдельные тулзы).
- **Вывод для карусели:** статичная карусель — **без звука**. Для роликов/Reels: закадровый голос RU с эмоцией → `text2speech_v2` variant `elevenlabs`; персонаж с голосом внутри видео → нативный аудио видео-модели (Kling Voice Binding / Seedance / Wan) вместо TTS+lipsync.

## 8. Грабли (сводка)

- **RU не гарантирован** ни у одного из 5 `text2speech_v2`, кроме подтверждённых Eleven v3, CosyVoice и Inworld. MiniMax/Seed Speech/VibeVoice — `⚠ проверить в MCP` перед RU-продакшном.
- `seed_audio` — **русский держит дословно**, проверено 02.08.2026 обратной расшифровкой: фраза вернулась слово в слово, цена 0,5–0,9 кредита. Прежняя запись «EN/ZH only, русский не прогонять» была выведена по бенчмаркам, а не по прогону, и оказалась неверной.
- Клонирование требует **явного consent** (юр-риск для КП).
- Лимит кастомных голосов ~3 — при батче разных персонажей может не хватить, проверять тариф.
- `dubbing` и общий TTS/клон имеют **разные списки языков** (10 vs 74+) — не полагаться на «74+» для dubbing-с-lipsync.

## 9. Свежесть (2025-2026)

- Eleven v3 API → **GA 14.03.2026** (Dialogue Mode + Audio Tags открыты только с этой даты).
- MiniMax Speech 2.8 (Native Sound Tags) → **23.01.2026**.
- Seed Audio 1.0 гайд обновлён **26.06.2026**; языковое расширение (EN/ZH → больше + до 10 мин) заявлено на **июль 2026** — `⚠ проверить в MCP`.
- CosyVoice 3.0 (декабрь 2025) — SOTA среди open-source TTS.
- Sora 2 (OpenAI) **discontinued**: web/app закрылись 26.04.2026, API — 24.09.2026. Миграция на Seedance 2.0 / Veo 3.1.
