# ОСИ ДИЗАЙНА — памятка арт-директора

> Оперативная памятка: собери стиль по осям и следи, чтобы база не перекашивалась в одну сторону.

## 🔢 ПОРЯДОК РЕШЕНИЙ (грамматика, сверено с источниками) — смысл → форма
Решай оси СТРОГО в этом порядке, каждый шаг сужает следующий:
1. **Смысл/контекст** (ЦА, боль, Awareness по Шварцу, Big Idea, целевое действие) — оси ещё не трогаем.
2. **Формат** (ось 8) — CREO-роль кадра + safe-zones + драм-роль.
3. **Настроение** (ось 7) — чувство за 50 мс, ДО цвета.
4. **Медиум** (ось 2) — «доказываем реальность или объясняем идею?» → фото/иллюстрация/3D/вектор. **ДО стиля!**
5. **Композиция+Типографика** (оси 4+5) — маршрут взгляда, веса, negative space **в grayscale ДО цвета** (не держит фокус в ч/б — цвет не спасёт).
6. **Стиль+Цвет+Фактура** (оси 1+6+3) — стиль ТОЛЬКО здесь, вытекает из Настроение+Медиум+Формат; цвет OKLCH 60-30-10; фактура обязательна.
7. **Модель+промпт-идея** (ось 9) — engine под задачу, промпт = цельная сцена.
⚠️ Стиль — НЕ старт (шаг 6). Медиум ДО стиля. Grayscale ДО цвета. Эстетика подчинена логике.

**Стиль = комбинация 9 осей.** Не бери «стиль по названию» — назови значение по каждой оси:
1. Направление · 2. Медиум (фото/типографика/вектор/3D/коллаж/**цифр.живопись**/**изометрия**/**SVG**) · 3. Фактура (зерно/глянец/хром/крафт/**фольга**) · 4. Композиция (центр/сетка/**layer-cake**/**split**/**негатив**/бенто/флэт-лей) · 5. Типографика (гротеск/жирный/дисплей/serif/**гуманистич.**/**дидон**) · 6. Цвет (один акцент; +**светлый-airy**) · 7. Настроение (техно/люкс/крафт/**авторитет**/**вдохновение**/**тайна**/**человечность**/**срочность**) · 8. Формат · 9. Модель.

**Если ни один из 37 пресетов не ложится — собери по осям** (сначала `GAPS §3`: Object-Poster, Reality-Warp, Warm Humanist Doodle, Solarpunk, Isometric System Map…), иначе склей значения осей в STYLE TOKEN сам.

**⚠️ Перекос базы — слепые зоны:**
- Медиум почти всегда «фото/типографика» → если нужно **тепло/объяснение**, бери цифр. живопись / изометрию / SVG.
- Композиция почти всегда «центр» → рассмотри layer-cake (лучший скан) / split (было-стало) / негатив (премиум-тишина).
- Фактура — **обязательна**, не опция (тренд Anti-AI: фактура = подлинность).
- Настроение под цель: стоп-скролл→тайна, доверие→авторитет, продажа→триумф/срочность, прогрев→вдохновение/человечность.

## ⚠️ ПЛАНКА «ИНТЕРЕСНО РАССМАТРИВАТЬ» (главный фильтр)
Кириллица без ошибок НЕ спасает, если смотреть неинтересно. Провал демо AYALA — тёмный минимализм, пустые зоны + абстрактные пятна вместо работ («чистый мусор; роботам может интересно, живым людям нет»). Каждый кадр обязан пройти 4 пункта (регистр любой — тёмный/светлый/яркий/hand-drawn):
1. **ПЛОТНОСТЬ** — весь кадр заполнен, НИ ОДНОЙ мёртвой пустой зоны. Пустой фон + строчка = слоп. (Негатив-приём ≠ пустота: даже он держит богатый focal.)
2. **ДЕТАЛИ/БОГАТСТВО** — глаз находит новое в каждом уголке (пропсы, микро-текст, иконки, скетчи, storyboard). «Из-за деталей прикольно».
3. **ХАРАКТЕР** — сильная эстетика с узнаваемым кодом или ремесленность, не «безопасный никакой».
4. **ЖИВОЙ ГЕРОЙ/КОНКРЕТИКА** — реальное лицо с эмоцией / персонаж / реальные примеры работ веером / реальные цифры-логотипы. НЕ абстрактные пятна.
Эталоны витрины работ: `steal-my-carousels` (светлый, огромная serif, веер реальных ярких карточек) · `@russgamzatov` (тёмный, но плотный: заголовок→YouTube-превью→ГЛАВНОЕ-список→CTA) · `@sifuyik` (hand-drawn пергамент, море скетч-деталей). Думать смело как фантазёр, не буквально-минимально.
