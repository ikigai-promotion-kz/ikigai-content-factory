# Как завести новый видео-стиль

> Рецепт, а не теория. Каждое правило здесь — чья-то потраченная попытка или кадр,
> на котором видно, что так не работает. Разбор, из которого он вырос, —
> `projects/plans/video-style-factory/`.
>
> Источник истины по стилям — `reels/lib/styles.mjs`. Проверяет и раскладывает
> `reels/lib/style-new.mjs`, зовётся через `node scripts/style-new.mjs`.

---

## Коротко

```
описание словами → черновик draft.json → node scripts/style-new.mjs draft.json
  → замечания исправлены → запись в styles.mjs (+ тема в overlay.mjs)
  → прогон одного куска → приёмка глазами → поле proof
```

Пока `proof` пуст, стиль **заявлен, а не доказан** — в клиентскую работу не берём.

## Что такое стиль в нашей фабрике

Каркас ролика общий у всех стилей: нарезка по фразам, панели по словам, драматургия,
строки-предохранители, свой звук. Стиль меняет **шесть вещей**: формулу для промпта,
среду за спикером, палитру плашек, тему оверлея, картинку-фон и анти-правила.
Различает стили не палитра, а **приём** (`signature`) — при одинаковом каркасе только
он и остаётся в памяти зрителя.

### Три режима — главное решение

Разбор десяти демо показал: стили делятся не по цене, а по тому, что происходит
с реальностью кадра.

| Режим | Что в кадре | Среда за спикером | Примеры |
|---|---|---|---|
| **A** | реальность сохранена, стиль живёт в декоре и на панелях-кульминациях | НЕ трогаем | кинетик, тёплый бренд, 3D-моушн |
| **B** | спикер вырезан и поставлен в новый мир, мир минимален | заменяем | стекло, обсидиан, гранж |
| **C** | агрессивный мир, спикер встроен в него элементом | заменяем | неон-тех, терминал, премиум, мем |

Режим выбирается первым: от него зависит, подставит ли движок формулу сохранения
спикера (`keepSpeakerLine`) и можно ли вообще закрыть стиль бесплатной вёрсткой.

### Три цены

| `tier` | Чем собирается | Цена |
|---|---|---|
| `theme` | CSS-тема оверлея: палитра, типографика, плашки | 0 |
| `scene` | тема плюс одна картинка-фон на полноэкранные кадры | центы |
| `generative` | генеративный монтаж куска через Omni | ~37 кредитов за кусок |

Правило согласованности: режим C бывает только `generative` — агрессивный мир
вёрсткой не собрать. Режимы A и B с темой могут быть `theme`/`scene`.

### Что вёрстка не догонит никогда

Пять признаков «перерисованного мира», по убыванию силы:

1. **Свет мира ложится на спикера** — лучи и контровой свет касаются лица. Плашка
   этого не даёт по построению.
2. **Текст — вещь в сцене**: гравировка на золоте, буквы с фаской, обрывок бумаги
   под скотчем, надпись на стекле с преломлением.
3. **Спикер встроен в мир**: круг-врезка с глоу-кольцом, видео-как-стикер.
4. **Среда заменена целиком** — частично закрывается картинкой-фоном.
5. **Живущий декор**: частицы, печать строк, тикающий счётчик — это вёрстка умеет.

Первые три — только генерация. Если стиль держится на них, `tier: 'generative'`.

## Десять шагов

**1. Проверить, что такого стиля нет.** `node scripts/style-new.mjs --list` — весь
каталог с «когда брать». Сосед в одну правку лучше нового стиля.

**2. Настроение и назначение** (`mood`, `whenToUse`, по-русски). Решается ДО эстетики:
тон задаёт средства, а не наоборот. Эти два поля кормят подбор — писать плотно,
синонимами, а не одним словом: сравнение токенов буквальное, без стемминга.

**3. Режим и цена** — по таблицам выше.

**4. Композиция и типографика** (`axes.kompoziciya`, `axes.tipografika`, `panelType`,
`textAsObject`, `axes.shots`). `panelType` — как набрана панель-кульминация; это
теряется, если описывать стиль одной формулой. Шоты — 2–4 типа из
`reels/knowledge/shot-vocabulary.md`, словарь не расширять.

**5. Медиум, фактура, цвет, свет** (`axes.medium`, `axes.faktura`, `axes.cvet`,
`palette`, `light`). Фактура обязательна — это анти-AI слой, без неё стиль выглядит
сгенерированным. `light` заполняется для режимов B и C: как мир освещает спикера.

**6. Формула** (`formula`, английский). По слоям, каждый — конкретным термином,
не прилагательным. «Премиальный» не заполняет ни один слой; `film grain`,
`halftone dots`, `volumetric beams` — разворачиваются моделью в целый кластер.
Доминантный термин ставить первым: ранние термины модель весит сильнее.

```
Format → Medium → Linework → Shading → Palette (СЛОВАМИ) → Texture →
Lighting & Mood → Composition → Motion → Cut-rhythm → Sound
```

Держать до 400 знаков: длинные формулы модель размывает.

**7. Среда** (`background`, английский) — одна фраза, где стоит спикер. Для режима A
это описание мира ПАНЕЛЕЙ, а не комнаты: среду там не заменяют.

**8. Приём** (`signature`) — одна фраза: что запомнит зритель. Не палитра, не шрифт,
а действие или объект. «Подпись на обрывке бумаги под скотчем», «сам кадр обрамлён
как наклейка», «фотореал b-roll без единой надписи».

**9. Анти-правила** (`extra`, английский). Что ломается именно в этом медиуме:

| Если в стиле есть… | В extra обязано попасть… |
|---|---|
| рваная бумага, обрывки | полоса шире текста, буквы не резать краем |
| металл, гравировка | светлый текст по тёмному, сильная фаска |
| код, терминал | код — только текстура, без смысла и без номеров строк |
| HUD с миниатюрами | миниатюры абстрактные, без лиц |
| стикеры, эмодзи | каждый эмодзи словами, литеральных нет |
| газетная вырезка | крупные чистые литеры одним шрифтом |
| рукописное, мел | подписи короткие и крупные: кириллица от руки плывёт |
| 3D-буквы в перспективе | одно-два коротких слова, целиком в кадре |
| заменённый мир на серию | список опорных объектов среды один на все куски |

**10. Риск** (`risk`, по-русски) — где стиль подведёт. Пустое поле значит «не думали»,
валидатор такое не пропускает.

## Черновик и проверка

```json
{
  "key": "arhiv-plenka",
  "style": {
    "name": "Архивная плёнка",
    "theme": null,
    "palette": ["#2A2018", "#D9B26A"],
    "formula": "…",
    "background": "…",
    "extra": "…",
    "mode": "B",
    "tier": "generative",
    "axes": { "napravlenie": "…", "medium": "…", "faktura": "…", "kompoziciya": "…",
              "tipografika": "…", "cvet": "…", "nastroenie": "…",
              "motion": "…", "cutRhythm": "…", "sound": "…",
              "shots": ["FULLSCREEN SPEAKER", "QUOTE-CARD"] },
    "mood": "…", "whenToUse": "…", "signature": "…", "panelType": "…",
    "textAsObject": true, "light": "…", "proof": null, "risk": "…"
  }
}
```

```
node scripts/style-new.mjs draft.json
```

Печатает замечания, а при чистом прогоне — профиль стиля, черновик темы для
`PRESETS`, промпт картинки-фона (если `tier: 'scene'`) и чек-лист приёмки.
Кредитов не тратит, файлов не правит: вставляет человек.

**Что валидатор не пропустит:** hex, таймкоды, имена файлов, эмодзи, кавычки и
русские буквы в англоязычных полях (модель печатает это прямо в кадр); пустые оси;
режим C с бесплатной ценой; тему, которой нет в `PRESETS`; текст-объект без
анти-правила; пустой риск.

## Тема оверлея

Черновик темы генератор печатает из палитры — это старт, а не результат: цвета плашек
дошлифовываются глазами по контрольным кадрам `look/`. Вставляется в `PRESETS`
(`reels/montage/overlay.mjs`), проверяется бесплатным прогоном:

```
node reels/montage/run.mjs <ваш-конфиг.mjs>
```

## Картинка-фон (tier scene)

Требования жёсткие, проверены партией, где два фона пришлось переделать: сплошная
фактура на весь кадр (не предмет на столе), **ни одной буквы**, пустой центр и низ —
там ляжет заголовок, ни людей, ни лиц. Промпт печатает генератор; класть в
`reels/knowledge/scene-backdrops/`.

## Приёмка

Первый кусок — и только потом остальные. Борд смотреть глазами ДО оплаты монтажа:
ошибка в русском на борде = ошибка в видео. Результат раскладывать на кадры **подряд**,
одиночный `-ss` дважды показывал ложную картину. Звук возвращать через
`reels/align-audio.mjs`.

Принят — заполнить `proof` (дата, файл-доказательство, вердикт) и записать урок
в `knowledge/lessons.jsonl`.
