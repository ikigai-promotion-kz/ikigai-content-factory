# Словарь шотов и драматургия Reels

> Читается в рантайме через `lib/corpus.js` → `getShotVocabulary()`, попадает в блок
> «СЛОВАРЬ ШОТОВ И ДРАМАТУРГИЯ» видео-корпуса.
>
> Источник словаря — метод AI-монтажа из AI Cube (сам он восходит к раскадровкам Павла).
> Взят как готовая насмотренность: перечень типов планов не изобретают заново.
> Стилевые пресеты — **наши**, из `reference/_STYLES/STYLES.md`, а не авторские.

## Типы шотов

Каждая панель раскадровки = один тип. В строке пишем: `таймкод + ТИП ШОТА + «слова из транскрипта» + драматургическая роль`.

| Тип | Что в кадре | Когда брать |
|---|---|---|
| `FULLSCREEN SPEAKER PUSH IN` | Спикер крупно, медленный наезд | Хук, открытие куска |
| `FULLSCREEN SPEAKER` | Спикер во весь кадр, статично | Прямое обращение, возврат к лицу |
| `CONTENT WITH CIRCLE` | Спикер в кружке + контент рядом | Каскад иконок, инфографика поверх речи |
| `FULLSCREEN CONTENT NO SPEAKER` | Полноэкранные титры или графика | Кульминация главной фразы |
| `TOP-SPLIT` | Верх — спикер, низ — контент | Таймлайны, гаснущие пункты |
| `SPLIT-SCREEN L/R` | Вертикальный сплит: спикер слева, контент справа | Сравнения, «было/стало» |
| `TERMINAL INSERT` | Тёмный терминал, строки печатаются | Технический контент, код, команды |
| `PHONE MOCKUP` | Мокап телефона или чата | Мессенджеры, приложения, переписка |
| `ZOOM-OUT REVEAL` | Начали с детали, отъезд раскрывает целое | Вау-момент, раскрытие масштаба |
| `DATA-COUNTER` | Крупные цифры накручиваются | Метрики, деньги, проценты |
| `QUOTE-CARD` | Карточка-цитата с атрибуцией | Пруф, отсылка, отзыв |
| `MATCH-CUT` | Переход по жесту спикера в графику | Щелчок, взмах — склейка «без шва» |
| `FULLSCREEN SPEAKER PUSH IN WARM` | Спикер, тёплый свет, наезд | Прощание, CTA |

## Что из этого умеет бесплатный монтаж (31.07.2026)

Перечень типов сверен с рабочим методом-первоисточником: совпадает один в один,
включая назначение каждого типа.

Реализовано оверлеем, без единого кредита — **шесть из тринадцати**:

| Тип | Как заказать |
|---|---|
| `FULLSCREEN SPEAKER PUSH IN` / `FULLSCREEN SPEAKER` | крупности `tight`, `mid`, `wide`, `drift` — подбираются сами |
| `CONTENT WITH CIRCLE` | `shot: 'circle'` |
| `TOP-SPLIT` | `shot: 'split'` |
| `FULLSCREEN CONTENT NO SPEAKER` | `takeover` на бите |
| `TERMINAL INSERT` | `takeover.screen.kind: 'terminal'` |
| `PHONE MOCKUP` | `takeover.screen.kind: 'phone'` |

Не реализовано: `SPLIT-SCREEN L/R`, `ZOOM-OUT REVEAL`, `DATA-COUNTER`, `QUOTE-CARD`,
`MATCH-CUT`, `PUSH IN WARM`. Первые четыре — чистый оверлей, то есть дешёвые; `MATCH-CUT`
требует распознавания жеста и остаётся ручным приёмом.

## Правила драматургии

- **Панель 1 всегда спикер-хук.** Первый кадр — лицо и первая фраза, не заставка и не логотип.
- **Кульминация главной фразы уходит в полноэкранные титры** (`FULLSCREEN CONTENT NO SPEAKER`), а не проговаривается на фоне говорящей головы.
- **CTA-слово видно текстом в последней панели** — не только звучит.
- **Смена панели каждые 1.5–2 секунды.** Дольше — зритель уходит.
- **Каждый кусок самодостаточен:** вырезали — остальное живёт.
- **Pattern interrupt на границе куска:** меняется план или обстановка. Это видео-аналог свайпа.

## Запреты (проверяются гейтом концепта до производства)

1. **Два одинаковых типа шота подряд** — не одобрять.
2. **Набор и порядок шотов повторяют прошлый ролик** — не одобрять, сверяться с реестром `reels/knowledge/shots-registry.jsonl`.
3. **Нет CTA** — не одобрять.

## Стилевые пресеты (наши)

Один пресет на ролик, два подряд не повторять. Полные профили — в `reference/_STYLES/STYLES.md`, здесь только пригодные для видео и то, чем они держат кадр в движении.

| Пресет | Чем работает в видео |
|---|---|
| **Швейцарская типографика** | Крупные титры на плашках, жёсткая сетка, один красный акцент. Кинетическая типографика ложится идеально. |
| **Технический нуар с чертежом** | Низкий ключ, физический чертёж в кадре (не HUD-накладка — запрет с 25.07). Драма без неона. |
| **Фото-натюрморт / флэт-лей** | Тактильные пруф-пропы, текст на реальных поверхностях. Рецепт, который заказчик принял с «наконец-то то что нужно». |
| **Ризограф-крафт** | Дуотон + halftone, печатная фактура вместо AI-глянца. Иллюстративные врезки. |
| **Нео-брутализм** | Кислотные плашки, гротеск во всю ширину. Для резких хуков и мем-регистра. |
| **Грейни-градиент / аура** | Зерно поверх градиента как анти-AI-сигнал. Для мягких, «личных» роликов. |

## Формат раскадровки

```
Часть N из M, пресет <название>. Раскадровка (6 панелей):
1. 0:00   FULLSCREEN SPEAKER PUSH IN — «первые слова хука» (зацепить)
2. 1:36   CONTENT WITH CIRCLE — «слова» (показать, о чём речь)
3. 3:16   FULLSCREEN CONTENT NO SPEAKER — «ключевая фраза» (кульминация)
...
```

Таймкоды берутся **из пословного транскрипта**, а не назначаются на глаз.
