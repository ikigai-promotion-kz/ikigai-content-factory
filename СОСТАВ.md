## Навыки — 7 штук

Ложатся в `<проект>/.claude/skills/`. Навык — это инструкция для Claude: он читает её сам,
когда вы формулируете задачу своими словами. Отдельных команд запоминать не нужно.

| Навык | Что делает | Когда берётся |
|---|---|---|
| **carousel-factory** | Карусели, слайды, баннеры, обложки: арт-дирекция, выбор стиля, текст слайдов, генерация картинок через fal, приёмка глазами и петля самообучения | «сделай карусель», «пост в инстаграм», «нужны слайды», «сделай баннер» |
| **reels-styles** | **Дефолт для видео.** Пересобирает ваш дубль внутри сгенерированного мира — газетный коллаж, обсидиан с золотом, матовое стекло, терминал, мел на доске, блокнот. Лицо ваше и живое, титры на чистом русском, речь ваша | «смонтируй в газетном стиле», «сделай рилс», любой стиль, названный словом |
| **reels-montage** | **Технический монтаж, не стиль.** Режет паузы, ставит каты по фразам, кладёт караоке-субтитры и титры поверх снятого как есть. Локально на ffmpeg, ноль затрат | только по явной просьбе: «вырежи паузы», «караоке-субтитры», «титры поверх» |
| **content-set** | Одна тема → целый выпуск: карусель + Reels + Stories + баннер в одном визуальном мире, с одного брифа. Дирижирует двумя навыками выше, держит единый STYLE TOKEN, показывает план и ждёт одобрения до трат | «сделай набор по теме», «нужен выпуск целиком» |
| **viral-scout** | Ищет, что уже работает в вашей нише, и превращает находки в идеи. YouTube и Shorts — бесплатно, Instagram — через Apify. Ранжирует по тому, насколько ролик обогнал собственный канал автора | «найди виралки», «что заходит в моей нише» |
| **publish-multichannel** | Публикация готового пакета сразу в несколько каналов: Instagram, TikTok, YouTube, LinkedIn, Facebook, X, Threads, Telegram, Pinterest. Через Upload-Post, с гейтом приёмки перед отправкой | «опубликуй везде», «выложи выпуск» |
| **factory-setup** | Ставит и чинит саму фабрику: окружение, ключи, проверка установки демо-роликом. Написан для человека, который не программист | «поставь фабрику», «проверь окружение» |

**Важное различие, на котором легко ошибиться.** `reels-styles` и `reels-montage` — разные вещи.
Стиль (мир вокруг спикера) делает только `reels-styles`. Если кредитов не хватает, он считает
смету и ждёт вашего решения — но **не подменяет стиль бесплатными плашками**. Ролик, собранный
такой подменой, был забракован 24.08.2026: человек видит «обычный монтаж» и решает, что фабрика
стилей не умеет.

## Движок — папка `engine/`

Скрипты, которые навыки запускают руками агента. Сами по себе они ничего не решают:
думает Claude Code, движок только считает, режет и рисует.

| Папка | Что внутри |
|---|---|
| `reels/` | видео-ветка: генеративный монтаж, нарезка, расшифровка, сборка выпуска, поиск доноров |
| `lib/` | общее: корпус знаний, генерация картинок, уроки, штамп бренда |
| `knowledge/` | знания фабрики: форматы, стили, ремесло видео, накопленные уроки |
| `reference/` | справочники стилей и разборов |
| `config/` | `models.json` — какая модель под какую задачу |
| `publish/` | публикация в каналы |
| `demo/` | демо-видео и его конфиг: на нём проверяется установка |
| `scripts/` | служебное |

### Что запускается напрямую

| Команда | Что делает | Стоит |
|---|---|---|
| `npm run check` | предполётная проверка: всё ли на месте, чтобы монтировать | бесплатно |
| `npm run demo` | монтирует демо-ролик — доказательство, что установка живая | бесплатно |
| `node reels/transcribe-local.mjs <видео>` | расшифровка речи на вашей машине, без интернета и ключа | бесплатно |
| `node reels/transcribe.mjs <видео>` | точная расшифровка через OpenAI | ~$0.006 за минуту |
| `node reels/scout/ig-scout.mjs "<тема>"` | поиск доноров: YouTube и Shorts | бесплатно |
| `node reels/scout/breakdown.mjs <видео>` | разбор чужой драматургии по фразам | бесплатно |
| `node reels/generative-run.mjs <видео> --style=<ключ>` | генеративный монтаж в стиле | кредиты Higgsfield |
| `node reels/release.mjs` | собрать папку выпуска под площадки | бесплатно |
| `node publish/publish.mjs <папка>` | публикация в каналы | по тарифу Upload-Post |

Все команды — из папки `engine`.

## Чего в комплекте нет

Честно, чтобы не искали:

- **автопостинга по расписанию из коробки** — расписание описано в `AUTOMATION.md` как отдельная
  настройка на своём сервере, готового планировщика внутри движка нет;
- **ключа Anthropic** — и это намеренно: думает за фабрику сам Claude Code, в котором вы работаете;
- **озвучки синтезом голоса** — расшифровка есть, генерация речи в движке не подключена;
- **наших ключей** — ни одного чужого ключа в комплекте нет, все поля в `.env` пустые.
