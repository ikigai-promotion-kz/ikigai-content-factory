# 🏭 Контент-фабрика IKIGAI PROMOTION

Комплект для участников интенсива «Контент-фабрика». Ставится в приложение Claude одним промптом и делает две вещи: **монтирует вертикальные Reels** из вашего видео и **собирает карусели, слайды и баннеры** — на вашей машине, без монтажёра и без дизайнера.

## Что внутри

| Что | Зачем |
|---|---|
| `plugins/content-factory/` | Скиллы для Claude Code: установка, монтаж видео, карусели и визуал |
| `engine/reels/montage/` | Монтажный слой: вырезка пауз, каты по фразам, субтитры, титры, пруфы |
| `engine/reels/transcribe.mjs` | Расшифровка речи с таймкодами каждого слова (платная, точнее) |
| `engine/reels/transcribe-local.mjs` | То же бесплатно и офлайн, на вашей машине |
| `engine/lib/corpus.mjs` | Выдача знаний под тему: стили, форматы, структура, анти-паттерны |
| `engine/lib/genimage.mjs` | Генерация слайдов и баннеров топ-моделями fal.ai |
| `engine/lib/lessons.mjs` | Петля дообучения: фабрика перестаёт повторять ваши правки |
| `engine/knowledge/lessons.jsonl`, `engine/knowledge/exemplars/` | Стартовая база петли: 27 наших уроков и 28 принятых работ как планка |
| `engine/reference/`, `engine/knowledge/` | ~800 КБ накопленных знаний: 37 стилей, разбор 183 каруселей, теория видео |
| `engine/demo/` | Демо-видео и конфиг — чтобы проверить, что всё встало правильно |
| `CLAUDE.md.template` | Правила вашего проекта: бренд, голос, стоп-слова. Переименуйте в `CLAUDE.md` |
| `.mcp.json.example` | Образец подключения fal.ai — скопируйте в `.mcp.json` корня рабочей папки |

## Кто в фабрике думает

Думает **Claude Code, в котором вы работаете**. Движок не ходит в модели за смыслом:
он подаёт Claude нужный кусок знаний, а Claude выбирает стиль, пишет сценарий и
принимает работу. Отдельный платный ключ к API Claude не нужен — вы уже платите за
подписку и второй раз за ту же модель платить не должны.

Деньги уходят в одном месте — картинка (fal.ai). Монтаж бесплатен полностью,
расшифровка речи может быть бесплатной: есть локальная (`transcribe-local.mjs`,
модель считается на вашей машине) и платная (`transcribe.mjs`, ~$0.006 за минуту).

## Установка

Полная пошаговая инструкция со скриншотами: **https://factorychecklist.ikigaipromotion.kz**

Коротко, если хочется сразу:

1. Приложение [Claude](https://claude.com/download), тариф Pro, вкладка **Code**. На Windows нужен [Git for Windows](https://git-scm.com/downloads/win).
2. Создайте папку (`C:\Claude\content-factory` или `~/Claude/content-factory`) и откройте её в Code → Local.
3. Вставьте в чат:

```
Поставь мне контент-фабрику IKIGAI PROMOTION в эту папку.

1. Склонируй https://github.com/ikigai-promotion-kz/ikigai-content-factory.git в подпапку factory
2. Прочитай factory/plugins/content-factory/skills/factory-setup/SKILL.md и действуй строго по нему
3. Скопируй обе папки скиллов из factory/plugins/content-factory/skills/ в .claude/skills/ этого проекта
4. Скопируй factory/CLAUDE.md.template в CLAUDE.md в корне рабочей папки и помоги мне его заполнить

Объясняй каждый шаг простыми словами и спрашивай разрешение перед установкой программ.
В конце прогони проверку и покажи мне готовый ролик.
```

### Чтобы фабрика была видна во всех проектах

Промпт выше кладёт скиллы в `.claude/skills/` **этой рабочей папки** — в другой папке их не будет. Хотите пользоваться фабрикой везде (в том числе из терминальной версии Claude Code, открытой на другом проекте) — поставьте комплект **плагином**:

- в приложении Claude: кнопка **+** рядом с полем ввода → **Plugins** → **Add plugin**, маркетплейс `ikigai-promotion-kz/ikigai-content-factory`;
- в терминальной версии: `/plugin marketplace add ikigai-promotion-kz/ikigai-content-factory`.

Приложение и терминальная версия — один движок с общими настройками, так что ставить нужно один раз.

### Своё видео

```bash
node reels/transcribe-local.mjs ./my-video.mp4       # расшифровка бесплатно, на своей машине
node reels/transcribe.mjs ./my-video.mp4             # то же платно и точнее (нужен ключ OpenAI)
cp reels/montage/example.config.mjs my.config.mjs    # образец конфига, каждое поле описано
node reels/montage/run.mjs my.config.mjs
```

### Карусель или баннер

Проще всего — попросить словами: «сделай карусель про <тему>», дальше скилл ведёт сам.
Под капотом это три команды:

```bash
node lib/corpus.mjs story "<тема>"                   # знания под смысл: структура, хуки
node lib/corpus.mjs art   "<тема>"                   # знания под визуал: стили, палитра
node lib/genimage.mjs "<промпт>" --out ./out/1.png --ratio 4:5 --model nano-banana-pro
```

### Как фабрика учится

Забраковали слайд — скажите почему, и она это запомнит:

```bash
node lib/lessons.mjs add "текст съехал за поле" --fix "заголовок короче 40 знаков" --tags слайд
node lib/lessons.mjs keep ./out/1.png --tags хук     # принятый слайд становится эталоном
node lib/lessons.mjs brief                            # что фабрика уже усвоила
```

Веса модели при этом никто не трогает. Просто перед каждой генерацией ваши правки и
принятые работы возвращаются в контекст — и та же ошибка больше не проходит. Чем
дольше работаете, тем точнее фабрика попадает в ваш вкус, а не в средний по интернету.

**Петля приходит не пустой.** В комплекте уже лежат **27 уроков** и **28 эталонов** —
наш собственный опыт за месяц ежедневных выпусков: где модель ломает кириллицу, почему
шаблонная вёрстка выглядит дёшево, чем пруф отличается от красивой пустоты. Это стартовая
планка, а не догма: ваши уроки ложатся сверху и со временем перевешивают наши.

```bash
node lib/lessons.mjs list                  # весь накопленный опыт
node lib/lessons.mjs brief "фото-натюрморт"  # что учесть по конкретному стилю
```

Эталоны лежат в `engine/knowledge/exemplars/` — откройте их глазами перед работой,
описание каждого есть в `index.jsonl`.

## Что нужно на машине

Claude поставит это сам, но для понимания: **Node.js 20+**, **ffmpeg**, **git**, браузер Chromium для Playwright (~150 МБ, качается один раз). Опционально `yt-dlp` — для скачивания чужих роликов.

## Сколько это стоит

Монтаж видео — **бесплатно**: ffmpeg и браузер работают локально, ни одного обращения к платным моделям.

Платить нужно только за генерацию и расшифровку речи:

| Сервис | Зачем | Порядок цен |
|---|---|---|
| Claude Pro | сам Claude Code | $20/мес |
| Higgsfield | картинки и видео, подключается коннектором без ключа | от $15/мес |
| fal.ai | картинки топ-моделями, точный текст на макете | оплата по факту, $5–10 на старт |
| OpenAI | расшифровка речи под субтитры — **необязательно** | ~$0.006 за минуту видео |

Расшифровку можно не покупать: `node reels/transcribe-local.mjs ./видео.mp4` считает
речь на вашей машине через встроенный в ffmpeg whisper. Модель качается один раз
(490 МБ) и дальше работает офлайн. Замер на 28-секундном ролике: 7,5 секунды работы,
текст слово в слово совпал с платной расшифровкой. На слабом ноутбуке рассчитывайте
примерно на длительность самого ролика.

## Правило, которое стоит запомнить

**Монтаж — это не генерация.** Титры, субтитры и врезки фабрика ставит слоем поверх видео: точный таймкод, чистая кириллица, ноль стоимости. Генеративные видео-модели посекундную раскадровку не выполняют — проверено на боевых прогонах. Модель нужна для картинки и оживления кадра, а не для текста в заданную секунду.
